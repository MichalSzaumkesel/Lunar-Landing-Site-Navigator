# Task W14: printable one-page mission brief

Write the files first, then test (see _common.md; UI-guidelines.md; RULES-quality.md).

Writable paths: src/components/print/** (new, with css and tests) only. Do not edit other files; the lead wires the button.

Goal: a 'Print brief' component (exported as PrintBrief and PrintButton from src/components/print/index.ts) that opens the browser print dialog for a clean light-theme, one-page A4 summary of the current scenarios (up to 4): title, UTC date range, site name and coordinates (from the bundle), badges text 'Synthetic data' or 'Approximate' where set, a compact table of the same metrics as the metrics panel (read them from the same metrics objects used by the cards, never recompute), the mission rules and whether they are met, a small static SVG sky plot per scenario at the current cursor (reuse the sky plot drawing helpers if they can render to an SVG string, otherwise draw a simplified polar plot from the horizon mask and track), the UTC time of the printout, the data provenance line (real or mock, source ids) and the footer 'Sun visible and Earth in view only, not a power or link guarantee'. Implementation: render the brief into a hidden container and use @media print rules so only it prints (the normal UI is hidden in print); white background, black text, no animations, colour-blind safe markers. Button label 'Print brief' with an aria-label. Tests: pure helpers for table rows and text formatting (units, dates in UTC, empty or null metrics shown as 'outside data range'), wording rule (no power, energy, signal or link claims). Acceptance: npm run typecheck, lint, test exit 0. Report short: STATUS, FILES, COMMANDS, OPEN.
