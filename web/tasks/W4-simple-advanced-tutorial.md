1. A **Simple** level for someone who has never seen the app: one place, a big sky view, a few plain sentences, Play. No jargon, no tabs, no tools except Copy link.

## Part 1: Simple view (`components/simple/`)

- `SimpleView.tsx` renders when `mode === 'simple'` instead of the board, panels and tools. Layout (two columns on wide screens, one column below 900 px): left the sky plot (`SkyPlot` for the active scenario, polar only), right a card with the place name, the date window in plain words and the **summary**; below both the Play button area is the global `Transport` (already in the shell). A "Copy link" button (`ShareButton`) sits top right of the card. No observer height, no slip, no scenario adding, no tabs.
- **Place picker**: three large buttons using the fixed demo ids `apollo_11`, `southpole_landed`, `artemis_region_1`; labels come from `dataSource.loadSites()` (`site.name`, strip a leading "[MOCK] " only for display) with the category as a small caption; the selected one is visibly pressed; clicking calls `applyPreset({ id, label, description, scenarios: [{ siteId }] })` style (check the `Preset` type in `config/presets.ts`) so there is always exactly one scenario. A site that fails to load is shown disabled with the text "Not available".
- **One date input** "Start date" (UTC date, clamped to the data range exactly like `ScenarioControls`, reuse `startBoundsMs` from `cardLogic.ts`) and nothing else about time.
- **Summary** (`simpleSummary.ts`, pure and tested): returns an array of short plain sentences generated from the metrics, the countdown events and the cursor sample, never typed numbers. Rules: sentence 1 about the Sun now ("The Sun is above the horizon." or "The Sun is below the horizon: the terrain or the Moon's curve hides it."), sentence 2 about the next change ("It sets in 31 hours." or "It rises in 12 hours." or "It does not set in the data."), sentence 3 about Earth now ("Earth is in view." or "Earth is hidden below the horizon.") plus its next change, sentence 4 about the window ("Over these 30 days the Sun is visible 49% of the time.") and sentence 5 about the longest dark stretch ("The longest dark stretch is 355 hours, about 15 days."), and sentence 6 about Earth over the window ("Earth is in view 36% of the time."). Hours above 48 are also given in days. When data is outside the range: "This date is outside the data we have." When the bundle is synthetic add a final line "This is demo data, not a measurement." Wording rule: never write power, energy, signal or link; only "Sun visible" ideas and "Earth in view" ideas. Tests for every branch.
- A **legend** under the sky plot in words: "Gold disc: the Sun. Blue disc: the Earth. Grey area: terrain that blocks the sky. Centre of the circle: straight up. Edge: the horizon."
- In Simple mode the top bar hides the observer height group and the preset bar shows nothing (the place picker replaces it); the mode switch stays. States: loading skeleton, error in plain words with "Try another place", outside data range.

## Part 2: Guided tour (`components/help/`)

- `tourSteps.ts`: pure data, two lists (`simpleSteps`, `advancedSteps`); a step is `{ id, target: string (CSS selector like '[data-tour="presets"]'), title, text, placement?: 'top'|'bottom'|'left'|'right' }`. A step whose target is not in the DOM when it is reached is skipped automatically (pure helper `nextAvailableStep(steps, index, direction, exists)` with tests).
- `Tour.tsx` + `useTour.ts`: a dimmed overlay with a cut-out (a positioned element with a huge `box-shadow` around the target rectangle) and a popover card next to the target (clamped inside the viewport; recomputed on resize and scroll; `scrollIntoView({ block: 'center' })` for targets). Card content: step title, text, "Step 3 of 12", buttons **Back**, **Next** (becomes **Done** on the last step; this is the single primary button of the card), **Skip tour**, and a checkbox "Don't show this again". `role="dialog"`, `aria-labelledby`, `aria-describedby`, focus moves to **Next** when a step opens and returns to the "?" button when the tour closes; `Escape` closes; `ArrowRight`/`ArrowLeft` next/back; Tab stays inside the card (simple focus trap). Respect `prefers-reduced-motion` (no animated transitions). The overlay does not block the page below the card from being read by screen readers: `aria-modal="false"`, the dimmer is `aria-hidden`.
- **Persistence**: key `lunar.tour.<mode>` in `localStorage` with value `done` when the user finishes, skips with "Don't show again" checked, or presses Skip (skipping also counts as dismissed for auto-start; the user can always reopen with "?"). Every `localStorage` access is in try/catch (it can throw); when storage is unavailable the tour auto-starts at most once per page load. Pure helper `shouldAutoStart(storageValue, suppressed)` with tests.
- **Auto-start** on the first visit of each level, 600 ms after the first card has rendered, unless the URL has `?tour=0` (for the presenter) or the user prefers reduced motion is irrelevant (it still starts). Switching level while the tour is open closes it; switching to a level never seen starts that level's tour.
- **"?" button** in `TopBar.tsx`: a ghost button with the visible text "Tour" and a "?" mark (`aria-label="Open the guided tour"`), always visible, reopening the tour of the current level from step 1 regardless of the stored state.
- **Do not trigger shortcuts**: update `shortcutAction` so it returns null while the target is inside an element with `role="dialog"` (extend the input type with `targetInDialog: boolean`) and update its tests.
